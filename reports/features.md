# Features

_Generated by `make features` (src/ipl_late_overs/features.py). Do not edit by hand._

## How history is computed

- **Earlier matches only.** Matches are ordered by (date, numeric match_id). A row's history uses only matches with a smaller position in that order: earlier dates, and on the same date (double-headers) only matches with a smaller match_id. Nothing from the current match is used.
- **Shrinkage.** `shrunk = (n x mean + k x league) / (n + k)`, with the league value also from earlier matches. k: {'bowler_late_overs': 10, 'bowler_economy_balls': 120, 'bowler_inn1_late_balls': 60, 'batter_balls': 100, 'batter_late_balls': 60, 'batter_dismissal_balls': 200}.
- **Low history.** Bowler with < 5 earlier late chase overs, or striker with < 60 earlier balls faced.
- **No NaN.** A player with no history gets the league value; the league value before the very first match uses the priors in config ({'late_over_runs': 8.5, 'economy': 7.5, 'inn1_late_economy': 9.0, 'strike_rate': 120.0, 'late_strike_rate': 140.0, 'dismissals_per_ball': 0.05}).
- **Sources.** Late-chase bowling history uses the late_overs table (same label definition). Economy, strike rate and dismissals use every parsed delivery except super overs, including D/L and no-result matches.
- **Runs conceded** = batter runs + wides + no-balls (byes and leg byes are not charged to the bowler). **Balls faced** excludes wides. **Dismissals** exclude retired hurt.

## Leakage checks

1. **Recompute from raw.** For 300 random rows (seed 20260101), the bowler's late-chase overs and mean, overs in all phases, and the striker's balls faced were recomputed directly from late_overs / deliveries filtered to earlier matches, independently of history.py. **All match** (the stage fails otherwise).
2. **Correlation with the label** (training seasons only). Threshold |r| > 0.9: **none flagged**. Largest |r|:
